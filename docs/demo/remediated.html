Limitations and scope

This is not a compliance attestation. aigov is a heuristic scorecard. It is not legal advice, not an audit and not a certification, and it does not attest compliance with any law, regulation or standard. NIST AI RMF functions are used only to organise the report.

  • aigov does not detect AI authorship. It reads what the team declares (manifest, file markers, commit trailers). The absence of signals does not prove that AI was not used.
  • All checks are heuristics based on file names and regular expressions. Expect false positives and false negatives.
  • Secret and personal-data detection covers a fixed set of formats (e.g. CPF, payment cards, well-known API key prefixes); other formats are not detected.
  • Provider detection reads Python, JavaScript/TypeScript and Go imports plus dependency manifests. Other languages are only covered through their dependency manifests.
  • Comment detection is line-based; multi-line strings and docstrings are scanned as code.
  • Commit trailers are read anywhere in the commit body, not only in the final paragraph.
  • Files over the size limit, binary files, symlinks and git-ignored env files are not scanned.
